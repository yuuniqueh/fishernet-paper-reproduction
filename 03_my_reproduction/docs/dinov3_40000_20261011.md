## 验证结果

下表所有 DINOv3 检查点均来自本次相同的 9,000 步全图训练与 GMM 初始化，
并使用相同 train / val 数据划分及双尺度 Fisher + SVM 协议。

| Fisher 更新步数 | val mAP |
| --- | ---: |
| 0：全图训练 + GMM 初始化 | 85.24% |
| 5,000 | 87.08% |
| **10,000** | **87.29%** |
| 20,000 | 87.25% |
| 30,000 | 87.26% |
| **40,000：最终模型** | **87.24%** |

最终模型相对本次 GMM 初始化提升 **2.00 个百分点**，相对同一次训练的 5,000 步仅提升
**0.16 个百分点**。10,000 步后指标基本进入平台，40,000 步没有超过本次所评估检查点中的最高值。
这支持“本次设置下早期训练有效、后续收益有限”，不能推断 AlexNet 也只需训练 4 轮。

500 次配对验证图像 bootstrap（种子 4242）中，40,000 步减去初始化的 mAP 差值，
95% 百分位区间为 **[1.35, 2.94] 个百分点**；40,000 步减去 5,000 步为
**[-0.27, 0.65] 个百分点**。后一个区间包含 0，不支持将微小点估计差异解释为稳定提升。
该分析只描述验证图像采样的不确定性；本次是单次训练，未测量训练种子之间的波动。

与此前 1,500 + 5,000 步短程试验的 86.30% 相比，最终结果提高 **0.94 个百分点**；
但全图训练预算、batch 和学习率日程也改变，不能将差值全部归因于 Fisher 阶段延长。
与历史 AlexNet 独立验证的 72.29% 相比高 **14.95 个百分点**，两者仍存在描述子、
图像尺度和模块学习率的差别，不能解释为严格的 backbone 单变量消融。

上述 87.24% 使用另行拟合的 SVM。最终 FisherNet 自带分类头的单中心裁剪验证 mAP
为 **81.92%**，属于另一种推理协议。

### 指标含义与论文比较

这里的 mAP 是 VOC2007 **图像多标签分类**的 20 类 AP 平均值，采用 11-point AP；
它不是整张图片所有标签均预测正确的比例，也不能直接与目标检测 mAP 比较。
87.24% 是最终检查点的验证结果，87.29% 是这次固定评估检查点中的验证集最佳值；
两者都不是独立 test 集结果。

[原论文第 4.1 节及表 1](https://arxiv.org/pdf/1608.00182#page=6)使用
VOC2007 trainval（5,011 张）训练、test 测试，报告 FisherNet-AlexNet 为 83.4%、
FisherNet-VGG16 为 91.7%。本次只用 train（2,501 张）训练、val（2,510 张）验证，
且预训练数据、backbone、描述子和图像尺度不同，不能据此宣称超过原论文或达到最新领先水平。

原论文同样在端到端训练完成后提取 Fisher Vector，进行 power normalization 与
L2 normalization，再训练 one-vs-rest 线性 SVM（C=1）用于最终评估
（[第 4.1 节，第 7 页](https://arxiv.org/pdf/1608.00182#page=7)）。
本次 Fisher + SVM 延续了这一评估方式；训练时仍由网络分类头及损失函数提供梯度，
SVM 在网络训练完成后单独拟合。

各类别 AP、完整配置、预测核对、参数更新审计和 bootstrap 见
[完整结果](../results/dinov3_40000_20261011.json)。逐步结果也保存于原始实验目录的
`validation_curve.csv`。

## 固定训练方案

| 设置 | 本次实验 |
| --- | --- |
| 数据划分 | VOC2007 train 2,501 张；val 2,510 张；不用 test |
| 全图阶段 | 9,000 步，batch 32；学习率在 3,000 / 6,000 步乘 0.1 |
| Fisher 阶段 | 40,000 步；micro batch 1，累积 2；20,000 / 30,000 步乘 0.1 |
| Backbone | 官方 DINOv3 ViT-S/16，本地权重；两个阶段均参与梯度更新 |
| Fisher 输入 | 最长边 224 / 336，保持宽高比；空间 token 投影到 256 维 |
| GMM | 1,000 张训练图像、50,000 个描述子、32 个对角协方差分量 |
| 优化器 | SGD，momentum 0.9，weight decay 0.0005；valid_mean masked BCE |
| 全图初始学习率 | backbone 1e-5；投影与分类头 0.01 |
| Fisher 初始学习率 | backbone 1e-5；投影 1e-4；Fisher 0.001；分类头 0.001 |
| 验证协议 | 双尺度原始 Fisher Vector 平均，再 signed sqrt + L2；train 拟合 LinearSVC，C=1；VOC07 11-point AP |
| 随机种子 | 42，单次训练 |

Fisher 训练为同一连续进程，在 5,000、10,000、20,000、30,000、40,000 步保留独立副本。
这些副本在训练完成后使用相同 SVM 协议评估；也评估 GMM 初始化模型，观察训练带来的变化。
固定完成 40,000 步，不根据验证结果改变训练时长或学习率。
最终 40,000 步结果与验证集最佳中间检查点将分别报告。

本次全图阶段与历史 AlexNet 均为 9,000 步、batch 32，Fisher 阶段均为 40,000 步、有效 batch 2。
但 backbone、描述子、图像尺度和模块学习率仍不同，因此这是训练预算匹配的方案比较，
不能把所有差异解释为单独更换 backbone 的因果收益。
与旧 DINOv3 1,500 + 5,000 步试验相比，全图预算和学习率日程也发生变化；
同一新实验内的 5,000 与 40,000 步比较更适合评估 Fisher 阶段延长训练的影响。
