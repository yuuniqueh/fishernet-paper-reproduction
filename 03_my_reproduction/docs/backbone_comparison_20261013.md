# DINOv2 与 DINOv3 对照

两种模型沿用同一套公共训练配置，从各自预训练权重开始，在 VOC2007 上独立训练。DINOv2-small 使用 patch 14 和 Transformers 后端，DINOv3 ViT-S/16 使用 patch 16、官方源码和本地权重。

## Test 结果

| 模型 | 全图 9,000 步 + GMM 初始化 | FisherNet 40,000 步 |
| --- | ---: | ---: |
| DINOv2-small | 89.40% | **89.97%** |
| DINOv3 ViT-S/16 | 86.88% | **87.67%** |

两阶段训练及 SVM 均使用 trainval 的 5,011 张图片，评估使用独立 test 的 4,952 张图片。最终模型和初始化对照在读取 test 指标前确定。

DINOv2 最终模型比 DINOv3 高 2.30 个百分点，500 次配对图像 bootstrap 的 95% 区间为 [1.37, 2.82] 个百分点。相对各自初始化模型，DINOv2 提高 0.57 个百分点，区间 [-0.45, 1.07]；DINOv3 提高 0.79 个百分点，区间 [0.51, 1.67]。这些区间反映图像采样变化，实验只有一个训练种子。

## Val 曲线

| Fisher 更新步数 | DINOv2 mAP | DINOv3 mAP |
| --- | ---: | ---: |
| 0：全图微调 + GMM 初始化 | 89.82% | 85.24% |
| 5,000 | 57.16% | 87.08% |
| 10,000 | 77.51% | 87.29% |
| 20,000 | 84.18% | 87.25% |
| 30,000 | 86.72% | 87.26% |
| 40,000 | 86.74% | 87.24% |

验证模型只在 train 的 2,501 张图片上训练，在 val 的 2,510 张图片上评估。它们与正式测试模型独立训练。

DINOv2 的 FisherNet 训练使 val mAP 下降 3.07 个百分点；DINOv3 提高 2.00 个百分点。最终 DINOv2 比 DINOv3 低 0.50 个百分点，配对区间 [-1.59, 0.35] 包含 0。相同配置下，两种模型的训练曲线并不相同。

## 配置

| 项目 | 设置 |
| --- | --- |
| 全图阶段 | 9,000 步，batch 32；新层 / backbone LR 为 0.01 / 1e-5，在 3k / 6k 衰减 |
| FisherNet 阶段 | 40,000 步，micro batch 1、累积 2；backbone / 投影 / Fisher / 分类头 LR 为 1e-5 / 1e-4 / 0.001 / 0.001，在 20k / 30k 衰减 |
| 优化器与损失 | SGD，momentum 0.9，weight decay 0.0005；`valid_mean` masked BCE |
| 特征 | 224/336 双尺度；256 维描述子、32 分量 GMM、16,384 维 Fisher Vector |
| GMM 采样 | 对应训练集 1,000 张图片、50,000 个描述子 |
| 分类器 | 双尺度原始 FV 均值 → signed sqrt + L2 → 线性 SVM，C=1 |
| 随机种子 | 42 |

两个阶段都更新 backbone。预训练数据、架构、patch 大小和运行后端随模型改变；双尺度、损失和较小学习率属于本项目设置。

三次新训练的实际步数、参数更新、GMM 与 SVM 收敛、预测 ID、标签和 mAP 重算均已核验。完整配置、各类 AP、预测哈希和配对统计见[结果 JSON](../results/backbone_comparison_20261013.json)，命令见[运行说明](../README.md)。
